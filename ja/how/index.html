SANの計算のしかた

SANは、生年月日・生まれた時間・生まれた場所・お名前から、韓国サジュ(四柱推命)・占星術・数秘術の三つを計算します。同じ誕生日を入れても、ほかの命式ツールと結果が少しちがうことがあります。多くの場合、下にあげる基準がちがうためです。SANが使っている基準を、ひとつずつ書いておきます。

ひと目でわかるまとめ

  • 生まれた時間は、時計の時間ではなく、生まれた場所の太陽に合わせた時間(真太陽時)に直して読みます。
  • 韓国のかつての標準時とサマータイム、ほかの国のタイムゾーンとサマータイムを反映します。
  • 四柱推命の年は立春で、月は節気で変わります。日付ではなく、節気に入る時刻で分けます。
  • 夜11時を過ぎて生まれた場合は、次の日の干支で読みます(基本の設定)。真夜中ごろに生まれた方は、結果の画面でもう一つの数え方に切りかえられます。
  • 旧暦(陰暦)の誕生日は、韓国天文研究院(KASI)の韓国の旧暦で陽暦に直します。
  • 計算はすべて、お使いのスマートフォンやパソコンの中で行います。ご入力の内容がサーバーに送られることはありません。

生まれた時間 — 時計の時間から太陽の時間へ

四柱推命では、生まれた時間の二文字(時柱)を、そのとき太陽が空のどこにあったかで決めます。ところが時計は、国や地域ごとに決めた基準の経線に合わせてあります。日本と韓国の時計は東経135度に合わせてありますが、東京は東経およそ139.7度にあるので、太陽は時計より19分ほど早く通ります。ソウル(東経127度)では、32分ほど遅くなります。そこでSANは、時計の時間を、生まれた都市の太陽の時間(真太陽時)に直して読みます。直すのは次の二つです。

  • 経度 — 生まれた都市が、その時計の基準の経線から東西にどれだけ離れているかの分を足し引きします(経度1度につき4分)。
  • 均時差 — 季節によって、太陽が時計より数分早かったり遅かったりするずれを足します(1年のあいだに約−15分から+16分)。

例：東京で11月3日の正午12時に生まれた場合、太陽の時間では午後0時35分ごろです(経度で+19分、均時差で+16分)。時柱が切りかわる時刻の近くに生まれた方は、この差で時柱が変わります。

生まれた時間がわからない場合は、時柱の二文字を空けて、六文字で読みます。太陽・月・惑星の位置はその日の正午で計算し、上昇宮(アセンダント)は出しません。

均時差は簡単な式で求めているため、1〜2分の誤差があります。時柱が切りかわる時刻から数分以内に生まれた場合は、結果が変わることがあります。

韓国のかつての標準時とサマータイム、ほかの国のタイムゾーン

生まれた時刻は、その日その場所の時計が指していたとおりにご入力ください。その日の時計が協定世界時(UTC)とどれだけずれていたかは、SANが調べて計算します。

  • 韓国の標準時 — 今はUTC+9です。1908年4月から1911年までと、1954年3月から1961年8月までは、UTC+8:30でした。
  • 韓国のサマータイム — 1948〜1951年、1955〜1960年、1987〜1988年の夏は、時計を1時間進めていました。
  • ほかの国 — お使いの端末に入っているタイムゾーンの情報から、その日の時差とサマータイムを調べます(日本で1948〜1951年に行われたサマータイムも含まれます)。タイムゾーンがいくつもある国は、都市ごとに見ます。
  • サマータイムの始まりで時計が飛ばした時刻と、終わりで二度あった時刻は、切りかわる直前の時差で読みます。

これに当てはまる場合は、「四柱推命」タブの「計算のしかた」に一行でお知らせします。

子の刻 — 夜11時から真夜中までに生まれた場合

一日の最初の刻である子の刻は、夜11時に始まり、午前1時に終わります。そのため、夜11時から真夜中までに生まれた人の「日」をどちらにするかには、二つの数え方があります。

  • 夜11時に日が変わると考える数え方 — 子の刻に入ったら、次の日の干支を日柱(生まれた日の二文字)に使います。
  • 真夜中に日が変わると考える数え方(夜子時・朝子時) — 夜11時から真夜中までは、その日の干支をそのまま使い、時間だけを子の刻として読みます。

SANは、基本として前の数え方を使います。ここでいう夜11時は、時計ではなく太陽の時間(真太陽時)です。東京で生まれた場合、時計では夜10時25分から10時56分ごろ(季節によって変わります)に日が切りかわります。

夜11時から午前1時までに生まれた方は、結果の「四柱推命」タブで、もう一つの数え方に切りかえられます。

年は立春で、月は節気で変わります

四柱推命の一年は、1月1日でも旧正月でもなく、立春(2月4日ごろ)に始まります。月も、毎月1日ではなく、十二の節気(立春・啓蟄・清明・立夏・芒種・小暑・立秋・白露・寒露・立冬・大雪・小寒)に入るときに変わります。

節気は、太陽が空の決まった位置に来る瞬間です。立春は太陽が黄経315度に来たときで、そのあと30度ごとに次の節気になります。SANは太陽の位置を天文学の計算式で求めて、その瞬間を分の単位まで探し、生まれた時刻がその前か後かで年と月を決めます。

例：2024年の立春は、2月4日の午後5時27分(日本・韓国の時刻)でした。この日の午後5時20分に生まれた場合はまだ前の年(癸卯)、午後5時30分に生まれた場合は新しい年(甲辰)になります。

生まれた時間がわからない場合は、その日の正午で分けます。リーディングの中の「今年」も、1月1日ではなく立春で切りかわります。

こうして求めた節気の時刻は、天文台が発表する時刻と1分以内で合っています。

旧暦の誕生日

旧暦で入力された誕生日は、陽暦に直してから計算します。1900年から2050年までは韓国天文研究院(KASI)が発表している韓国の旧暦に従い、2051年から2100年までは韓国の時刻で計算した値を使います。閏月も選べます。その年にない閏月や、29日までしかない月の30日は受け付けません。

大運 — 10年ごとに変わる大きな流れ

  • 向き — 生まれた年の上の文字(天干)が陽か陰かと、性別で決まります。陽の年に生まれた男性と、陰の年に生まれた女性は順に進み(順行)、その反対は逆に進みます(逆行)。性別を選ばなかった場合は女性の数え方で計算し、リーディングにもそう書いてあります。
  • 始まる年齢 — 生まれた時刻から、次の節気(順行)または前の節気(逆行)までの日数を3で割ります。3日を1年と数える計算です。四捨五入して、1歳から10歳のあいだにします。
  • そのあと — その年齢から10年ごとに、生まれた月の二文字(月柱)から一つずつ前か後ろへ進みます。

占星術

太陽・月・惑星の位置は、天文学の計算式で求めた、地球から見た位置です。星座は、春分点から数える西洋占星術の十二星座です。上昇宮(生まれた瞬間に東の地平線からのぼっていた星座)は、生まれた時刻と、生まれた都市の緯度・経度から求めるので、時間がわからない場合は出ません。

計算した位置は、実際の空とほぼ同じです。ただし、星座が切りかわる時刻の近くに生まれた場合は、生まれた時刻が数分ちがうだけで結果が変わることがあります。

数秘術

数秘術は、生年月日とお名前を数字に変えて読みます。一桁になるまで数字を足していくのが基本です。ただし11・22・33は、そのまま残します。

例：1990年6月15日 → 1+9+9+0 = 19 → 1+9 = 10 → 1+0 = 1、6月 = 6、15 → 1+5 = 6。全部足すと 1+6+6 = 13 → 1+3 = 4。ライフパスは4です。

名前の数字は、お名前をローマ字にして、一文字ずつ決まった数字(A=1、B=2 … I=9、J=1にもどる)を足して出します。日本語の画面では、ひらがな・カタカナのお名前をローマ字に直して使います。漢字だけのお名前は、数字に変える計算をしません。

知っておいていただきたいこと

  • 計算は決まった規則に従いますが、リーディングの文章は、その結果をSANが読むひとつの読み方です。楽しみと参考としてご覧ください。健康・大きなお金・法律にかかわることは、専門家と相談して決めてください。
  • ほかの命式ツールと結果がちがうときは、真太陽時を使っているか、子の刻をどう数えるか、サマータイムを反映しているかを、まず見くらべてみてください。
  • 生まれた時刻が正確でないと、時柱と上昇宮が変わることがあります。はっきりしない場合は、「生まれた時間がわからない」を選ぶほうが安心です。
